产品与项目经验

P01 / PROJECT · AutoAgents.ai · 2024.07 – 2026.09

AgentsPro 海外中小商家 AI 社媒运营工具 效果评测 · Prompt 与输入设计 · 发布链路验收

项目背景
海外中小商家需要持续产出社媒内容，却缺少请代理公司或专职运营的预算。
项目内容
多 Agent 架构（竞品分析 → 策略 → 内容创作 → 分发），以结构化 JSON 任务单交接；生成内容并自动排期发布到 Instagram / Facebook / LinkedIn。
我的职责
负责内容生成模块：建评测集与三档评分、制定 Critic 四维 Rubric、bad case 归因驱动 Prompt 与微调迭代、结构化语气输入、发布链路验收。
项目成果
主平台内容直接采纳率约 52%；专业服务类“可直接发布”比例约两个季度从不到 40% 提升至接近 50%，餐饮、电商促销类接近 55%。
技术 / AI 能力
多 Agent · JSON 任务单评测集 + Rubric失败模式归因Prompt 产品化

P02 / PROJECT · 智象未来 HiDream.ai · 2023.09 – 2024.03

Pixeling 千象 AIGC 视觉创作平台 AI 产品经理助理（实习）｜ 模型评测 · 用户反馈 · 竞品分析

项目背景
面向 C 端的 AIGC 视觉创作产品，基于自研视觉多模态模型提供文生图、文生视频，V1.0 于 2023.08 上线。
项目内容
上线后密集迭代期：文生视频时长由 4 秒扩展至 15 秒以上（2023.12），“千象万相”小程序上线（2024.02）。
我的职责
协助产品经理做模型版本评测、用户反馈整理、AIGC 竞品分析与小程序上线验收。
项目成果
评测集约 40 → 约 70 条，覆盖 6–7 个迭代节点；约 1,000 条原始反馈归并为 80 余个问题项；部分验收 UI 问题发布前修复。

P03 / PROJECT · 独立产品 · DeskTidy

DeskTidy 一键收起桌面 Vibe Coding

项目背景
干活时同时开着 ChatGPT、Claude、浏览器和飞书。窗口越堆越多，一切换就开始掉帧。
项目内容
原生 Mac 菜单栏应用，macOS 13 起可用。一键清理只隐藏、不关闭。
我的职责
产品定义 · 交互把关 · 规则约束 · 与 AI 结对做出原生 Mac 应用
项目成果
第一版功能已经能装在自己的 Mac 上每天用：菜单栏常驻，关掉终端也不会退出。
