产品与项目经验

P01 / PROJECT · 转转集团 · 拍照 3.0 + AI 定级

转转·二手手机外观成色 AI 定级系统 产品定义 · 评测体系 · 人机协同设计

项目背景
成色定级依赖质检师人眼目检，主观、标准不一、易误判，质检产能成为回收规模化瓶颈。
项目内容
标准化采集 + AI 缺陷识别 + 规则定级 + 人工复验；影子运行 → 辅助预填 → 分流直通 → 扩机型放量四阶段推进。
我的职责
找需求·定边界·定标准·建评测·设分流·促闭环。
项目成果
定级一致率 ≥ 85%，高估率 ≤ 2%，直通率 ≥ 70%；单台定级约 90 秒 → 约 35 秒，错误率约 8% → 4%。
技术 / AI 能力
目标检测 + 实例分割规则引擎定级置信度分流数据飞轮

P02 / PROJECT · 腾讯 · C 端会员业务

腾讯·会员权益中心 与续费体验优化 产品实习生 → 产品经理助理 → 产品经理 ｜ 用户调研 · 转化路径设计 · 数据复盘

项目背景
会员权益展示分散、说明不清，续费路径步骤多，权益使用率低、到期续费流失明显。
项目内容
重构会员首页信息架构与权益说明，设计优惠领取与到期续费提醒，简化续费流程。
我的职责
用户访谈、问卷与续费漏斗定位流失环节；输出 PRD 与原型，协同上线，A/B 实验验证。
项目成果
权益领取率与续费页转化率提升，续费流程步骤减少；遵循到期提醒与便捷退订规范，控制客诉风险。

P03 / PROJECT · 独立产品 · DeskTidy

DeskTidy 一键收起桌面 Vibe Coding

项目背景
干活时同时开着 ChatGPT、Claude、浏览器和飞书。窗口越堆越多，一切换就开始掉帧。
项目内容
原生 Mac 菜单栏应用，macOS 13 起可用。一键清理只隐藏、不关闭。
我的职责
产品定义 · 交互把关 · 规则约束 · 与 AI 结对做出原生 Mac 应用
项目成果
第一版功能已经能装在自己的 Mac 上每天用：菜单栏常驻，关掉终端也不会退出。
