P02 / PROJECT · 转转集团 · 2025.03 — 2026.09

二手回收台账与
账目异常预警助手

AI 应用运营 / 业务流程优化 · 大模型做语义抽取，确定性代码做金额勾稽，人机协同处理异常。

01

项目背景

  • 二手数码代理回收依赖手写回收单、聊天报价、验机扣款和转账截图，人工录入台账。
  • 录入慢、行话易错、多笔扣款易漏；异常靠周/月结事后对账才发现。

02

项目内容

  • OCR 多模态识别 + LLM 结构化抽取 + 垂类行话字典 + 规则引擎，输出可追溯台账。
  • 上传后按红黄绿分流：算式不平、低置信度、IMEI 缺失、转账与实付不一致时转人工复核。

03

我的职责

  • 定义 12 个核心字段与金额公式，固化验收边界。
  • 建立 200+ 脱敏历史台账基准集，按手写、行话、多笔扣款、转账截图分层评测。
  • 维护机型 / 成色 / 扣款字典（如“15pm / 大花 / 靓机”映射为标准枚举），并做 Bad Case 归因。
  • 把金额公式、红黄绿阈值和人工放行权限写入 PRD 与验收用例。

04

项目成果

  • 12 个核心字段覆盖台账必填项。
  • 行话 / 成色映射准确率 92%+；金额与扣款提取准确率 75% → 96%+。
  • 单张复杂单据：人工 3–5 分钟 → 30–40 秒。
  • 异常发现：周 / 月结事后对账 → 上传后准实时预警。
