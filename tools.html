07 / TOOLS

常用工具

日常做 AI 产品时常用的几款工具：对话梳理、原型开发、编辑代码与执行任务。

  • Claude

    AI 对话助手

    常用来长文档阅读与总结、PRD 与方案的文字推敲、复杂问题的结构化梳理。

    claude.ai ↗

  • ChatGPT

    AI 对话助手

    常用来头脑风暴、用户场景与竞品信息梳理、快速查资料和改写文案。

    chatgpt.com ↗

  • Cursor

    AI 编程 IDE

    常用来把原型想法做成可运行的 Demo：读懂项目代码，小步修改、调试与验证。

    cursor.com ↗

  • VS Code

    代码编辑器

    常用来查看和编辑代码、Markdown 文档与配置文件，配合插件处理日常开发。

    code.visualstudio.com ↗

  • Grok Bot

    桌面 AI 助理

    常用来把跨应用、跨网页的多步任务交给 AI 队友执行，关键步骤由我确认。

    x.ai/bot ↗

  • Pi Agent

    终端编程 Agent

    常用来在终端里让 Agent 读写文件、运行命令，处理脚本和小型自动化任务。

    pi.dev ↗

Logo 与名称归各自所有者，仅用于指代对应产品。
